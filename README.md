# MAREA · App de clientes

App web instalable (se agrega a la pantalla de inicio del celular) para los clientes de MAREA y el panel del coach.

- **Cliente:** crea su cuenta con el link del coach → elige membresía (queda pendiente hasta que el coach confirme el pago) → llena su valoración inicial (8 pasos, enfoque PAR-Q+ y resistencia a la insulina) → ve su inicio.
- **Coach (dueño):** entra con su cuenta y ve a sus clientes, activa membresías registrando el pago y lee cada valoración con semáforo de seguridad.

Datos en Supabase (seguridad por fila). Se publica con GitHub Pages desde la rama `main`, sin compilar nada.

Ajustes (nombre del coach, WhatsApp, conexión) en `js/config.js`.
